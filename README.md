# 🦊 RedFox-GKI-Kernel-Tecno-LI6 (`RedFox-Ultimate`)

> **Кастомное GKI-ядро для смартфона Tecno Spark 20 (`LI6`, чипсет MediaTek Helio G85 / `mt6768`) с нативной поддержкой `KernelSU + SuSFS`, оптимизацией сетевого стека `TCP BBR` и ускорением работы памяти `ZRAM ZSTD`.**

## 🛠️ Инструкция по установке

### Шаг 1. Обязательное резервное копирование
Перед любыми манипуляциями **обязательно снимите бэкап** разделов `boot_a`, `boot_b`, `vendor_boot` и `vbmeta` с вашего **Tecno Spark 20 (`LI6`)** (через `mtkclient`, `fastboot` или `adb shell dd` при наличии временного рута).

### Шаг 2. Перепаковка (если в релизе только `Image.gz`) или подготовка `boot.img`
1. Распакуйте ваш стоковый `boot.img` с помощью `magiskboot` или `unpack_bootimg`.
2. Замените файл ядра (`kernel`) на скачанный **`Image.gz`** / **`Image`** из релиза.
3. Соберите новый `boot_redfox_li6.img` и при необходимости подпишите его через `avbtool`.

### Шаг 3. Прошивка через `Fastboot`
1. Переведите **Tecno Spark 20 (`LI6`)** в режим **`Bootloader (Fastboot)`**:
   ```bash
   adb reboot bootloader
   ```
2. Прошейте образ ядра сначала в активный слот **`boot_a`** (оставив рабочий стоковый образ в `boot_b` как резерв) и перезагрузите смартфон:
   ```bash
   fastboot flash boot_a boot_redfox_li6.img
   fastboot reboot
   ```
3. После загрузки системы откройте **KernelSU Manager** и убедитесь, что статус отображается как **«Работает»**.
4. *(Опционально)* После успешной проверки всех функций телефона (связь, Wi-Fi, камера, звук) продублируйте ядро и во второй слот: `fastboot flash boot_b boot_redfox_li6.img`.

## 🔄 Подробная инструкция: Чистая установка прошивки / GSI (Wipe Data + возврат ядра RedFox)

Если вы планируете сделать полный сброс данных (**Wipe Data / Factory Reset**) или установить новую прошивку / GSI на **Tecno Spark 20 (`LI6`)**, придерживайтесь безопасного трёхэтапного цикла через **[RedFox-Flasher](https://github.com)** или `fastboot`:

1. **Этап 1 — Временный возврат стокового `boot` (для работы Stock Recovery и `fastbootd`):**
   - Переведите смартфон в режим **`Bootloader (Fastboot)`** (`adb reboot bootloader`).
   - Временно прошейте ваш резервный стоковый образ `boot_stock.img`:
     ```bash
     fastboot flash boot_a boot_stock.img
     fastboot flash boot_b boot_stock.img
     ```
2. **Этап 2 — Очистка памяти (`Wipe Data`) и прошивка системы:**
   - Перезагрузите смартфон в рекавери (`fastboot reboot recovery`), выполните **Wipe Data / Factory Reset** и при необходимости прошейте новый образ системы в режиме `fastbootd` (`fastboot flash system system.img`).
   - После завершения прошивки перезагрузите устройство обратно в **`Bootloader (Fastboot)`** (`fastboot reboot bootloader`).
3. **Этап 3 — Установка кастомного ядра RedFox и запуск:**
   - Прошейте подписанный образ **`boot_redfox_li6.img`** и запустите Android:
     ```bash
     fastboot flash boot_a boot_redfox_li6.img
     fastboot flash boot_b boot_redfox_li6.img
     fastboot reboot
     ```
   - После загрузки откройте **KernelSU Manager** и проверьте статус работы ядра.
